# Русская история Лилит

Пакет `ru-lilith` содержит 47 файлов и 586 строк основной игры и Examtaker. Плагин перенаправляет чтение штатных текстовых файлов на `HelltakerAILab/localizations/ru-lilith`. Исходные файлы игры продолжают служить базой для режима `original`.

Имя героини в портретах — Лилит; обращения и глагольные формы согласованы с женским родом. Разговор о солнечных очках адаптирован под светлую прядь Лилит. Финальная сцена Examtaker связывает героиню с её прежней историей и блинчиками.

## Редактирование

Редактируемый источник — `localization/ru-lilith/translations.json`. Ключ — относительный путь исходного файла, значение — массив строк. Каждый индекс используется сценарием игры, поэтому число строк и пустые позиции сохраняются.

```powershell
python scripts/build_localization.py --game "C:/Games/Helltaker-Lilith"
```

Команда сверяет индексы с собственной копией игры и записывает готовые UTF-8 файлы в `packs/ru-lilith`. Скопируйте эту папку в `HelltakerAILab/localizations/ru-lilith` и перезапустите игру.

Название шрифта задаётся полем `font` в `pack.json`. Стандартное значение — `Georgia`. Плагин проверяет кириллицу и подбирает размер текста в пределах игровых панелей. Цифровой таймер Examtaker использует исходный Segment7.

Настройка языка в `HelltakerAILab/localization.json`:

```json
{"active_pack":"ru-lilith"}
```

Значение `original` выбирает штатный текст. Команда API `localization_status` возвращает активный пакет, число файлов и строк, шрифт, ошибки загрузки и параметры видимых текстовых элементов.

Покрытие файлов и сохранение индексов проверены автоматически. В Unity подтверждены главное меню, кириллица, меню паузы и возвращение к игре. Полный просмотр сюжетных развилок — следующий этап проверки редакторских формулировок и вёрстки.
